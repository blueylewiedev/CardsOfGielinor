Cards of Gielinor: privacy and data

An unofficial fan plugin for the RuneScape 3 Client API. Last updated 18 November 2026.

The short version. The plugin saves your collection on your own computer and sends nothing about you anywhere. It makes one optional web request, when the client starts, for a public file of card updates. That request contains no information about you or your character.

What the plugin reads

To work out your credits and to know whose collection is whose, the plugin reads, through the client's plugin API:

  • the XP you gain in each skill, and your Slayer task and kill counts;
  • your boss kill counts, and which NPCs are near you (so it can tell a boss kill from a kill of anything else);
  • your character's unique tracking identifier, if you have granted the optional trackingAccess permission, or your character's name if you have not.

It does not read your account credentials, chat messages, friends list, inventory or bank.

What it saves, and where

It saves your collection, your credits, some totals for the Statistics window (packs opened, credits earned and spent, time played with the plugin) and your settings. They are kept by the game client in the plugin's own storage, on your computer, against your character's tracking identifier (or name). None of it is uploaded. Because it never leaves your computer, the developer holds none of it.

The one web request

If you have granted the optional httpAccess permission, the plugin makes one plain GET request each time the client starts, to https://blueylewiedev.github.io/CardsOfGielinor/overlay.jsonl, a public file on this website. The request carries no cookie, identifier, name or any other information about you or your character. The file is read, used and forgotten when the client closes; the plugin does not save it. Without the permission the plugin simply works from the cards and numbers it shipped with.

This website is hosted by GitHub Pages. As with any web request, the server can see your IP address and the usual details of a request (the time, the browser or client name). GitHub's own handling of that is described in its privacy statement. The developer does not receive or see those logs.

What is in the file

Card corrections and new cards, so they can reach you between plugin versions. The same file can also carry a few numbers and on/off switches, so a mistake in them can be corrected without waiting for a new version: the credits earned for an amount of XP, the price of a pack, how often each rarity and finish is pulled, the credits for Slayer kills and boss kills, and switches for a credit source or an effect.

  • It is data only. The plugin never downloads or runs code, and never shows text from the file other than card text.
  • Every number has limits that are fixed in the plugin's reviewed code; a value outside them is ignored. A switch can only turn something off.
  • It never touches what you own. It changes what you earn and pay from then on, not the cards or credits you already have.
  • The file only applies to the plugin version it was made for.

The current contents are public: the cards in overlay.jsonl and the numbers and switches in tuning.json ({} means none are changed). The plugin's source, including the limits, is at github.com/blueylewiedev/CardsOfGielinor.

The tracking identifier

With trackingAccess the plugin saves your collection against your character's tracking identifier, so it survives a rename. The identifier is used only on your computer, as the name of your save. It is never part of a web request, so the two permissions are never combined.
